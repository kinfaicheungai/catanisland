# 拓荒群島 Frontier Isles

原創手機六角島嶼策略遊戲。1 位玩家對 3 位電腦玩家，支援離線單機遊玩。

## 開始遊戲

在 Mac 雙擊「啟動拓荒群島.command」，或在資料夾內執行 `npm start`，再開啟 http://127.0.0.1:4174。

## 玩法特色

- 開局階段由你親自喺棋盤揀選村莊同相連航線嘅位置，之後三位電腦拓荒團亦會逐一喺棋盤上選址。
- 擲骰有實體點數骰仔動畫同音效；生產物資時會有資源卡由島嶼飛入你嘅物資欄。
- 電腦回合會逐步喺棋盤上顯示佢哋擲骰、收成同建造，模擬真人對局嘅節奏。
- 右上角 🔊 可隨時開關音效。
- 擲出 7：海盜可由擲骰者移到任何島嶼封鎖生產並掠奪對手；物資超過 7 份要棄一半（你可自選棄邊啲）。
- 航海卡入手牌，喺「🃏 手牌」按需打出：騎士（移海盜掠奪）、豐收（任選兩資源）、築路（免費兩條路）、勝利點（即時計分）。
- 手機版面：建造／交換／抽卡收埋喺「⚒ 建造」抽屜，主畫面只留擲骰／結束回合同手牌，慳位。

## 規則摘要

- 每輪擲兩粒骰，數字相符的島嶼會生產物資。
- 19 塊六角地緊貼拼成大六角島，每家以一座村莊和一條相連航線開局。
- 航線必須連接現有網絡；村莊建在合法交點，亦可升級成港城。
- 五種產品港提供 2:1，一般港提供 3:1，無港口則為 4:1。
- 可購買航海卡：騎士、豐收、築路及勝利點。
- 支援按鈕縮放及手機雙指縮放。
- 擲出 7 會遇上海盜，持有超過 7 份物資者損失一半。
- 率先取得 10 勝利點勝出。

## 離線遊玩（Service Worker）

本遊戲透過 `sw.js` 將所有檔案快取落機。**第一次要喺有網絡下開啟一次**，之後即使完全熄網／飛航模式都照玩到——遊戲行時完全唔需要上網。

- 更新版本後，`sw.js` 內 `CACHE` 版本號會一齊升，開啟時自動換走舊快取。
- Service Worker 只喺 `https://` 或 `http://127.0.0.1`／`localhost` 生效（本機啟動器同 Vercel 都符合）；用 `file://` 直接開唔會離線。

## 資源分配審查（v2.9.7，無代碼改動）
針對「數字唔對應」嘅懷疑做咗嚴謹審查：交點幾何 vs 拓撲鄰接（標準島 54 交點、零重複、100% 一致）、海盜封鎖、生產派發、骰面＝生產數字，全部正確，未發現 bug。已加入迴歸測試防止將來改壞。
說明：每座村莊／城市會由佢接觸嘅「所有」2–3 塊地塊生產；而大部分數字（3,4,5,6,8,9,10,11）喺棋盤上各有「兩塊」，所以擲 6 可能同時涉及一塊礦石6同一塊羊毛6，海盜亦只封其中一塊。羊毛顯示 0 通常係因為起村／升城用晒。
