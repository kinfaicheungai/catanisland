# 拓荒群島 Frontier Isles

原創手機六角島嶼策略遊戲。1 位玩家對 3 位電腦玩家，支援離線單機遊玩。

## 開始遊戲

在 Mac 雙擊「啟動拓荒群島.command」，或在資料夾內執行 `npm start`，再開啟 http://127.0.0.1:4174。

## 規則摘要

- 每輪擲兩粒骰，數字相符的島嶼會生產物資。
- 19 塊六角地緊貼拼成大六角島，每家以一座村莊和一條相連航線開局。
- 航線必須連接現有網絡；村莊建在合法交點，亦可升級成港城。
- 五種產品港提供 2:1，一般港提供 3:1，無港口則為 4:1。
- 可購買航海卡：騎士、豐收、築路及勝利點。
- 支援按鈕縮放及手機雙指縮放。
- 擲出 7 會遇上海盜，持有超過 7 份物資者損失一半。
- 率先取得 10 勝利點勝出。
